# 🌍 Meridian Travel Landing Page

A modern and responsive travel agency landing page built using HTML5, SCSS, Bootstrap 5, and Vite. The project focuses on clean layout, responsive design, reusable styles, and a premium travel-focused user interface.

---

## 🚀 Live Features

- Responsive Navigation Bar
- Hero Section
- Travel Search Section
- Popular Destinations
- Travel Packages
- Traveler Testimonials
- Newsletter Subscription
- Footer with Navigation Links
- Responsive Grid Layouts
- Hover Effects
- Custom Travel Cards
- Responsive Mobile Navigation
- Reusable SCSS Variables
- Bootstrap 5 Components and Utilities
- Clean Typography
- Modern Travel Agency UI

---

## 🛠️ Technologies Used

- HTML5
- SCSS (Sass)
- Bootstrap 5
- Vite
- JavaScript
- CSS Flexbox
- CSS Grid


### Build for Production

```bash
npm run build
```
